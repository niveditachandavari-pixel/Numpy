# NumPy Fundamentals for Machine Learning & Data Processing

A comprehensive practical guide to numerical computing using **NumPy**, the core library for high-performance array operations, matrix manipulations, and mathematical computations in Python.

---

## Technical Overview

NumPy (Numerical Python) provides multi-dimensional array objects (`ndarray`), high-level mathematical functions, and efficient linear algebra operations. It serves as the underlying foundation for the scientific Python ecosystem, integrating seamlessly with libraries like **Pandas**, **Matplotlib**, and **Scikit-Learn**.

### Key Features Covered
* **Installation & Setup**: Environment configuration via `pip`.
* **Array Initialization**: Creating 1D/2D arrays, typed arrays, and zero-initialized matrices.
* **Array Inspection**: Checking structural metadata (`.shape`, `type()`).
* **Element-Wise Operations**: Vectorized multiplication and mathematical operations.
* **Slicing & Indexing**: Array slicing and conditional (boolean) masking.
* **Reshaping & Restructuring**: Modifying array dimensions dynamically using `.reshape()`.
